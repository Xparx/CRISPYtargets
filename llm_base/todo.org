   Requires the =mainscworkspace= conda env (pandas, pyranges, pyfaidx, pysam,
   biopython); the smoke and liftover tests skip themselves when java/FlashFry or
   minimap2 are absent.
   - [X] Feature-extraction tests for Doench 2016 (feature order, GC/normalization)

   - [X] =idmapping/lift_snps.py= round-trip test with known expected positions
   - [X] Promoter extraction strand handling (=tests/test_prepare_targets_promoters.py=)

   Writing the suite surfaced three real bugs, all fixed:
   1. =prepare_targets= raised =KeyError= on any GFF3 whose TSS features occupy
      only one strand (draft/region-filtered/organellar annotations, or a
      =--tss-features= label mismatch). PyRanges returns a column-less frame
      for an empty subset. Now guarded, with a warning on label mismatch.
   2. Reverse-strand 5' flank for Doench 2016 was read 3bp inside the
      protospacer. On the - strand the 23-mer is read as revcomp, so the PAM
      sits at forward [g, g+3) and the flank must start at g+23, not g+20.
   3. =lift_snps= lifted every position downstream of an indel to the wrong
      coordinate. minimap2 was run without =-c= so no =cg:Z: CIGAR was
      emitted, and =load_from_paf= treated each whole record as one collinear
      block. Now emits =-c= and splits records into blocks at indels.
